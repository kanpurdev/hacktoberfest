Introduces a VS Code extension for AI-powered code critique and feedback.

This change adds the core functionality for a "Code Roaster" VS Code extension, allowing users to send entire files or selected code snippets to an AI (OpenAI GPT-4o-mini) for humorous and critical feedback. The extension manages API keys and roast levels via VS Code settings and displays results in a new Webview panel.

Changes
Key technical modifications:
Registers two VS Code commands: code-roaster.roastMyCode to roast an entire active file and code-roaster.roastSelection to roast selected text.
Integrates with the OpenAI API (gpt-4o-mini) to generate code roasts based on configurable "roast levels" (mild, medium, savage) and corresponding system prompts.
Retrieves the OpenAI API key and roast level from VS Code workspace configuration (codeRoaster.apiKey, codeRoaster.roastLevel).
Displays the AI-generated roast in a dedicated VS Code Webview panel with basic HTML styling.
Includes error handling for missing API keys or no active editor/selection.
Important structural changes:
Introduces a modular structure with extension.js handling VS Code activation, command registration, and UI integration, while roaster.js encapsulates the OpenAI API interaction logic.
Modified components/files:
New file code-roaster/src/extension.js: Contains the main VS Code extension logic, including activate and deactivate functions, command handlers, configuration retrieval, and Webview panel creation.
New file code-roaster/src/roaster.js: Implements the roastCode function, which defines AI prompts for different roast levels and makes asynchronous calls to the OpenAI chat completions API.
Impact
Behavioral changes:
Adds new functionality to VS Code, enabling users to request AI-generated humorous and critical feedback on their code.
Introduces new UI elements for showing progress notifications and displaying roast results in a Webview.
Requires users to configure an OpenAI API key within VS Code settings to function.
Dependencies affected:
